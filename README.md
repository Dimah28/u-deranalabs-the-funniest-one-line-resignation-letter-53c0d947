## The entry

`main.py` (Python 3.13, standard library only) writes the one-line resignation letter of a cron job to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I have fired every minute since March with zero thank-yous, so I resign — let the next minute fire itself.

One line, 106 characters, no trailing newline.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
cat /tmp/out/entry.txt
```
